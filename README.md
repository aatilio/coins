# COINS

Cotizador de criptomonedas con analisis de precios y graficos historicos, usando la API de CoinGecko.

## Funcionalidades

- **Top 20 criptomonedas** por market cap en cards
- **Cotizacion en vivo** con precio, cambio 24h, volumen y market cap
- **Barra de posicion** que muestra si el precio esta cerca del minimo o maximo del dia
- **Analisis historico** con ATH (tope historico) y ATL (fondo historico) con porcentajes
- **Grafico de precios** con Chart.js (7d, 30d, 90d, 1a)
- **Multiples divisas**: USD, EUR
- **Modo oscuro / claro** con toggle
- **Busqueda** de criptomonedas en tiempo real
- **Diseno responsive** adaptable a movil
- **Cache** con localStorage para evitar rate limit

## API

[CoinGecko API](https://www.coingecko.com/en/api) (sin necesidad de API key)

## Tecnologias

- HTML5
- CSS3
- JavaScript Vanilla
- Chart.js
